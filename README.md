# 残り物献立

冷蔵庫の残り物を入れると、AI（Google Gemini）が献立と分量を考え、足りない食材だけの買い物リストを作ります。
買い物リストは、LINEなどにそのまま貼れるテキストで出ます。スマホとパソコンのどちらでも使えます。

公開先: https://ilovepenegalu-art.github.io/kondate/

## 使い方

1. **残り物**: 食材を書きます（量も書くと、足りるかどうかの判断が正確になります）。人数・日数・品数を選んで「献立を考える」。
   - 「旬の食材も使う」にチェックを入れると、いまの月（端末の日付）に旬の食材を使った料理が入ります（1日1品以上）。旬の食材は買い物リストに入り、献立では「旬」の印が付きます。
   - 残り物を空にしてチェックを入れれば、旬の食材だけで献立を考えます。
2. **献立**: 料理ごとに、材料（手元にある／買う）と作り方の要約が出ます。気に入らない料理は「差し替え」。くわしい作り方は「『料理名 レシピ』を検索」から見られます。
3. **買い物リスト**: 足りない食材が、献立全体でまとめて出ます。家にあるものはチェックを外します。「コピー」か「LINEなどに送る」で妻に共有します（共有用テキストは「買うもの」と「作るもの」だけ。リンクは入れません）。

- 基本調味料（塩・しょうゆ・油など）は、初期設定では「家にある前提」でリストから外れます（チェックを入れれば入ります）。
- 途中で「中止」できます。
- AIはWeb検索をせず、定番の家庭料理の一般的な分量で考えます（無料枠では、今のモデルで Google 検索が使えないため）。

## はじめの準備

### 1. Gemini の APIキーを作る

Google AI Studio（aistudio.google.com）で APIキーを作ります（無料枠あり）。ワークスペースアプリで使っているキーを、そのまま使えます。

### 2. アプリをネットに置く（スマホから使うため）

このアプリは `index.html` など数ファイルだけで動きます。サーバーやデータベースはいりません。GitHub Pages に置いています。

直したときは、GitHub のリポジトリで「Add file」→「Upload files」から、直したファイルをドラッグして「Commit changes」。1〜2分で反映されます。

ページ自体は誰でも開けますが、APIキーは各端末の中にしかないので、ほかの人があなたのキーを使うことはできません。

### 3. 各端末で開く

- スマホ・パソコンで公開先のURLを開き、右上の ⚙ で APIキーを保存します（端末ごとに1回）。
- スマホは「ホーム画面に追加」すると、アプリのように開けます。ホーム画面から開いてキーが消えていたら、もう一度保存してください。

## 無料枠について

- モデルは `gemini-3.8-flash` です（無料枠で1日20回まで）。「献立を考える」「差し替え」を1回押すごとに、1回と数えます。
- 足りなければ、⚙ の「モデル」を `gemini-3.5-flash-lite` にすると、1日500回まで使えます（そのぶん考えが浅くなることがあります）。
- 今の上限と使った回数は、Google AI Studio のレート制限の画面で確認できます。上限に達すると、アプリにメッセージが出ます。
- **無料枠では、送った内容（残り物・要望）が Google の製品改善に使われ、人が読むことがあります。** 他人の情報などは入れないでください。

## データの保存

すべて、その端末のブラウザの中（localStorage）に保存します。どこにも送りません（AIへの問い合わせを除く）。

| 保存するもの | 中身 |
|---|---|
| APIキー・モデル | ⚙ で保存したもの（「キーを消す」で削除） |
| 前回の入力 | 残り物・人数・日数・品数・要望 |
| 前回の献立 | 最後に作った献立（次に作ると上書き） |
| 買い物リストのチェック | 手で付け外ししたもの |

スマホとパソコンの間で、データは同期しません。ブラウザの履歴・サイトデータを消すと、これらも消えます。

## AIの呼び出しについて

- AIが動くのは「献立を考える」「差し替え」を押したときだけです。1回押すと1回だけ呼びます。自動実行・自動リトライはありません。
- ブラウザから直接 Gemini API を呼びます。キーはURLではなくヘッダーで送ります。
- AIを呼ぶコードは `index.html` の `callGemini` だけです。別のAIに差し替えるときはここを直します。

## ファイルの構成

```
index.html             アプリ本体（画面・AI呼び出し・買い物リストの計算）
manifest.webmanifest   ホーム画面に追加したときの名前・色
icon.svg               アイコン
```
