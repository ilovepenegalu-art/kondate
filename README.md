# 残り物献立

冷蔵庫の残り物を入れると、AI（Google Gemini）がGoogle検索でレシピを確かめながら献立を考え、足りない食材だけの買い物リストを作ります。
買い物リストは、LINEなどにそのまま貼れるテキストで出ます。スマホとパソコンのどちらでも使えます。

## 使い方

1. **残り物**: 食材を書きます（量も書くと、足りるかどうかの判断が正確になります）。人数・日数・品数を選んで「献立を考える」。
2. **献立**: 料理ごとに、材料（手元にある／買う）、作り方の要約、参考レシピの検索リンクが出ます。気に入らない料理は「差し替え」。
3. **買い物リスト**: 足りない食材が、献立全体でまとめて出ます。家にあるものはチェックを外します。「コピー」か「LINEなどに送る」で妻に共有します（共有用テキストは「買うもの」と「作るもの」だけ。リンクは入れません）。

- 基本調味料（塩・しょうゆ・油など）は、初期設定では「家にある前提」でリストから外れます（チェックを入れれば入ります）。
- 生成には少し時間がかかります。途中で「中止」できます。
- 作り方はAIが短くまとめたものです。くわしくは参考レシピを見てください（本文は転載していません）。

### 参考レシピのリンクについて

Gemini は、検索で見たページの直接のURLを返しません（Google経由の転送用URLだけを返します）。AIにURLを書かせると実在しないURLになることがあるので、次のようにしています。

- 料理ごとのリンク: 「レシピ名＋サイト名」のGoogle検索。たいてい一番上に、そのレシピが出ます。
- 献立の下の「AIが参考にしたページ」: 検索で実際に見たページ（Google経由のリンク）。
- その下の「Google検索の候補」: Google検索を使ったときに表示が求められているものです（Gemini API の規約）。

## はじめの準備

### 1. Gemini の APIキーを作る

Google AI Studio（aistudio.google.com）で APIキーを作ります（無料枠あり）。ワークスペースアプリで使っているキーを、そのまま使えます。

### 2. アプリをネットに置く（スマホから使うため）

このアプリは `index.html` など数ファイルだけで動きます。サーバーやデータベースはいりません。
スマホからも開けるように、無料の GitHub Pages に置くのがおすすめです。

1. GitHub で新しいリポジトリを作り、このフォルダのファイル（`index.html`・`manifest.webmanifest`・`icon.svg`）を入れます。
2. リポジトリの Settings → Pages で、公開するブランチ（`main`、フォルダは `/`）を選びます。
3. 数分で `https://ユーザー名.github.io/リポジトリ名/` が開けるようになります。

ページ自体は誰でも開けますが、APIキーは各端末の中にしかないので、ほかの人があなたのキーを使うことはできません。

### 3. 各端末で開く

- スマホ・パソコンで上のURLを開き、右上の ⚙ で APIキーを保存します（端末ごとに1回）。
- スマホは「ホーム画面に追加」すると、アプリのように開けます。

## 無料枠について

- モデルは `gemini-3.8-flash` です（Google検索と、決まった形での返答を同時に使えるモデル）。無料枠で使えます。
- Google検索にも回数の枠があります。1回の生成で、AIが何回か検索します。「差し替え」も1回ごとにAIを呼びます。
- 上限に達すると、アプリにメッセージが出ます。今の上限は Google AI Studio（`aistudio.google.com/rate-limit`）で確認できます。
- **無料枠では、送った内容（残り物・要望）が Google の製品改善に使われ、人が読むことがあります。** 他人の情報などは入れないでください。
- モデルが使えなくなったとき（「モデルが見つかりません」と出たとき）は、⚙ の「モデル」で別の名前に変えられます。

## データの保存

すべて、その端末のブラウザの中（localStorage）に保存します。どこにも送りません（AIへの問い合わせを除く）。

| 保存するもの | 中身 |
|---|---|
| APIキー・モデル | ⚙ で保存したもの（「キーを消す」で削除） |
| 前回の入力 | 残り物・人数・日数・品数・要望 |
| 前回の献立 | 最後に作った献立（次に作ると上書き） |
| 買い物リストのチェック | 手で付け外ししたもの |

スマホとパソコンの間で、データは同期しません。ブラウザの履歴・サイトデータを消すと、これらも消えます。

## AIの呼び出しについて

- AIが動くのは「献立を考える」「差し替え」を押したときだけです。1回押すと1回だけ呼びます。自動実行・自動リトライはありません。
- ブラウザから直接 Gemini API を呼びます。キーはURLではなくヘッダーで送ります。
- AIを呼ぶコードは `index.html` の `callGemini` だけです。別のAIに差し替えるときはここを直します。

## ファイルの構成

```
index.html             アプリ本体（画面・AI呼び出し・買い物リストの計算）
manifest.webmanifest   ホーム画面に追加したときの名前・色
icon.svg               アイコン
```

## 今回入れていないもの

レシート画像の読み取り、栄養管理、カレンダー連携、ログイン・複数ユーザー、苦手食材・アレルギーの除外、LINEへの直接送信。
